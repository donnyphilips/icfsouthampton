# Immanuel Christian Fellowship – Southampton

A premium, Christ-centered church website for the ICF community in Southampton. This site features a modern, cinematic design with smooth transitions and interactive storytelling.

## Features
- **Premium Animations**: GSAP-powered section reveals and creative photo effects.
- **Horizontal Scrolling**: Storytelling panels with parallax and 3D depth.
- **Responsive Design**: Optimized for mobile, tablet, and desktop viewing.
- **Cinema Hero**: Full-screen video intro with particle effects.

## Technologies Used
- HTML5 & Vanilla CSS
- JavaScript & GSAP (GreenSock Animation Platform)
- ScrollTrigger & Lenis (Smooth Scroll)
- YouTube API Integration

## Setup
To run this project locally:
1. Clone the repository.
2. Open `index.html` in any modern web browser.
